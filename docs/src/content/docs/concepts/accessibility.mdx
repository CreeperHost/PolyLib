PolyLib includes accessibility option registration and sync helpers for mods that need player-facing preferences.

## Main Areas

- `AccessibilityOptionsRegistry` registers options.
- `AccessibilityRegistrationBuilder` configures option metadata.
- `AccessibilityPrefsManager` stores and receives preference values.
- `AccessibilityPolicy` describes how player values interact with server config.

Generated class pages show the exact builder and registry signatures for the selected release.
