PolyLib includes data store classes and sync protocols for block entities and modular containers.

## Main Areas

- `TileDataManager` and `DataManagerBlock` handle block-entity state.
- `DataManagerContainer` and `ModularGuiContainerMenu` handle container state.
- `data.serializable` contains typed stores for primitive and Minecraft data values.
- `containers.network` contains sync protocol helpers.

Generated API pages are useful when checking exact method signatures for the selected release.
