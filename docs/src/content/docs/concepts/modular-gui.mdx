Modular GUI is PolyLib's client-side GUI system. It is built around `GuiElement`, geometry constraints, content elements, rendering helpers, and container-backed data sync.

## Useful Areas

- `client.modulargui.elements` contains ready-made GUI elements.
- `client.modulargui.lib.geometry` contains layout and constraint primitives.
- `client.modulargui.lib.container` connects GUI state to menus and synced data.

The generated reference exposes the release-specific public types and methods for these packages.
