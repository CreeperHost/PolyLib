PolyLib wraps common Minecraft registration patterns behind `PolyRegistry` and loader-specific implementations.

Use the registry helpers when you want a common code path to register items, blocks, menus, and creative tabs across Fabric and NeoForge.

## Main Types

- `PolyRegistry<T>` creates registry queues for a mod ID and a Minecraft registry key.
- `IRegistryFactory` supplies the loader-specific registry implementation.
- `PolyScreens` bridges menu and screen registration.
