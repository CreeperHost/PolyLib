PolyLib is a Minecraft modding library for shared loader abstractions, events, registration, Modular GUI, networking, data sync, and accessibility helpers.

## Install

PolyLib is published to the CreeperHost Maven repository.

```gradle
repositories {
    maven { url "https://maven.creeperhost.net" }
}

dependencies {
    implementation "net.creeperhost.polylib:polylib-fabric:VERSION"
    implementation "net.creeperhost.polylib:polylib-neoforge:VERSION"
}
```

Use the version selector in the header when you need documentation for a specific released build.
