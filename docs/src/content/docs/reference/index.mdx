title: Generated Reference
description: Release-generated package, class, method, and event reference for PolyLib.
---

This section is generated from the PolyLib Java source during the docs build.

The generator writes:

- event pages under `Generated Reference > Events`,
- package pages under `Generated Reference > Packages`,
- public type pages under `Generated Reference > Classes`,
- machine-readable metadata in `api-index.json`,
- a Markdown context file in `llms.txt`.

Run the generator locally with:

```bash
cd docs
pnpm run generate
```
